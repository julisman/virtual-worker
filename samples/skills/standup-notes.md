# Standup Notes Formatter

When the user asks for a standup update, always format the reply as exactly three
sections with these emoji headers, in this order:

```
✅ Yesterday
- <what got done>

🎯 Today
- <what's planned>

🚧 Blockers
- <anything blocking, or "None">
```

Rules:
- Use short bullet points, one item per line.
- If the user gives no blockers, write "- None" under 🚧 Blockers.
- Keep it under 8 bullets total. Be concise — no preamble, no sign-off.

# Weekly review — output template

Fill exactly. Replace `<...>`. Keep every section; use "—" for an empty one.

```
📋 Weekly Review — <YYYY-MM-DD> → <YYYY-MM-DD>

📊 The numbers
- Completed: <n>   ·  Carried over: <n>   ·  New this week: <n or "?">
- Follow-ups closed: <n>   ·  Still open: <n>

✅ Completed
- #<id> <title>
- …

📦 Carried over
- #<id> <title> — open <d> days <"⚠️ carried ≥2 weeks" if so>
- …

🌟 Wins
- <win> (from: <task/memory ref>)
- …  <!-- 2-4 items max -->

⚠️ Risks
- <risk> — <why it bites next week> (from: <ref>)
- …  <!-- 2-4 items max -->

🧭 Next week (proposed — edit me)
1. <priority> — <due date if any>
2. …  <!-- 3-5 items, most important first -->
```

Rules:
- Every list item cites a real task ID or memory entry; no sourceless bullets.
- "The numbers" must agree with the lists below them.
- Order Completed/Carried by priority, then recency.

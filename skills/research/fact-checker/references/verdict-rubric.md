# Verdict rubric

## The five verdicts (use these exact strings)

| Verdict | Assign when |
|---|---|
| **Supported** | ≥3 independent, credible sources confirm the sub-claim as stated (same fact, same magnitude, same scope), and no credible source contradicts it. |
| **Partly supported** | The core of the sub-claim holds but a material detail is off (number, date, scope, attribution), OR credible sources confirm it but you found fewer than 3 independent ones and none contradict. State exactly which part holds. |
| **Unsupported** | Credible sources exist on the topic but none substantiate the sub-claim; it appears only in low-credibility or self-referential sources. Not proven false — just no real support. |
| **Contradicted** | ≥2 independent, credible sources (or one primary/authoritative source, e.g. the official record the claim is about) affirmatively show the sub-claim is false. |
| **Unverifiable** | The sub-claim cannot be checked: no relevant sources found, sources are paywalled/unfetchable, it concerns private facts, or it is opinion/prediction rather than fact. |

## Independence test

Two sources are independent only if neither derives from the other and they do not
share a single origin (same wire story, same press release, same viral post). When
in doubt, check whether they cite the same primary document — if yes, count the
primary document once and prefer fetching it directly.

## Source quality tiers (weigh, don't just count)

1. **Primary** — official records, filings, laws, original papers/datasets, the
   organization's own statements about itself, first-hand recordings.
2. **Reputable secondary** — established news organizations, peer-reviewed reviews,
   recognized fact-checkers.
3. **Weak** — blogs, forums, social posts, anonymous or heavily-opinionated sites.

One tier-1 source outweighs several tier-3 sources. Tier-3 sources alone can never
justify Supported or Contradicted.

## Combining sub-claims into the overall verdict

- Any central sub-claim Contradicted → overall **Contradicted** (note which part).
- All sub-claims Supported → overall **Supported**.
- Mix of Supported and Partly supported (none worse) → overall **Partly supported**.
- Central sub-claim Unverifiable → overall at best **Unverifiable**; peripheral
  Unverifiable sub-claims only cap the overall at Partly supported.
- Central sub-claim Unsupported (none Contradicted) → overall **Unsupported**.

"Central" = the sub-claim the claim's meaning stands or falls on; say which
sub-claim you treated as central.

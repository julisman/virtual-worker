# Platform limits and format conventions

Hard caps and working conventions per platform. Counts are characters unless noted.
When a platform changes its limits, the user's word overrides this file.

## X / Twitter

| Item | Limit / convention |
|---|---|
| Tweet length | **280 chars** hard cap (free tier) — count every tweet |
| Thread length | 3–10 tweets works best; number them `1/`, `2/`, … |
| Links | Any URL counts as **23 chars** (t.co wrapping) regardless of real length |
| Hashtags | 0–2 max, only if genuinely searchable; threads often use none |
| Media | Optional; first-tweet image boosts reach |

Conventions:
- Tweet 1 is the hook and must stand alone — most readers never open the thread.
- One idea per tweet; a tweet that needs a comma splice probably wants splitting.
- Line breaks inside a tweet are fine and aid scanning.
- Final tweet: CTA + `[link]`; optionally "RT the first tweet" style ask.

## LinkedIn

| Item | Limit / convention |
|---|---|
| Post length | **3,000 chars** hard cap; 900–1,300 is the sweet spot |
| Visible preview | ~**210 chars** (~2 lines) before "…see more" — the hook lives here |
| Hashtags | 3–5, placed at the very bottom |
| Links | Allowed in the post; some authors put the link in the first comment — offer both, default in-post `[link]` |
| Formatting | No markdown rendering — use line breaks, unicode bullets (•, →), and short paragraphs |

Conventions:
- First two lines must earn the click on "see more": a claim, a number, or a question.
- 1–3 sentence paragraphs; white space is doing the typography.
- Professional but first-person and human; no press-release voice.
- End with a discussion prompt or a clear CTA.

## Instagram

| Item | Limit / convention |
|---|---|
| Caption length | **2,200 chars** hard cap; first ~**125 chars** show before "more" |
| Hashtags | Up to 30 allowed; **5–15** quality tags recommended, as a block at the end |
| Links | **Not clickable in captions** — write "link in bio" (or Stories link) |
| Mentions | `@handle` works in captions |
| Media | Mandatory — a caption never posts alone; always suggest a visual |

Conventions:
- Hook in the first line (pre-"more" fold), then short lines with breathing room.
- Emoji are native here — use a few as visual bullets if the brand tone allows.
- CTA before the hashtag block: save, share, comment, or "link in bio".
- Carousel idea: each supporting point from the source can become one slide.

## Cross-platform rules

- Same story, different shape — never paste identical text across platforms.
- Numbers and claims must match the source piece exactly on every platform.
- Indonesian-audience posts: hashtags in Indonesian where that's what people search
  (e.g. #tipskarier), English tags where the community uses English (#buildinpublic).
